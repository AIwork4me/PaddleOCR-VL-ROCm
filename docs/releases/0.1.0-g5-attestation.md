# 0.1.0 G5 Maintainer Attestation

Date: 2026-07-17

Decision: **G5 PASS**

## Scope decision

The project maintainer explicitly waived an empty-cache public-network
installation as a v0.1.0 release requirement on 2026-07-17. The attempted
download reached GitHub and its release CDN, but transferred at approximately
27 KiB/s and was stopped with a 9,437,184-byte partial file. This record does
not call that attempt successful and does not turn a network limitation into an
installer or checksum failure.

The waiver is limited to transport from the public release CDN. Manifest
verification, installation, runtime activation, DirectML/HIP operation, both
documented server journeys, package installation, and repository quality
checks remain required.

## Accepted Windows validation

on Windows build `10.0.26200`, an AMD Radeon(TM) 8060S Graphics device,
`amdhip64_7.dll`, and llama.cpp build `9884` (`86961efd5`).

- A new root was populated with the five pinned files from a previously
  verified cache. `setup --no-start` independently rechecked every declared
  size and SHA-256, extracted the runtime, verified its version, and activated
  the configuration. The packaged runtime manifest SHA-256 was
  `90d1e6b819b47f4da73e8028d0548a980cc51e27d070e38d5a67f274c3bc8334`.
- Python 3.11 Doctor passed Windows, AMD GPU, HIP, disk, runtime, all five
  resources, DirectML-first layout execution with fallback disabled, and the
  selected server endpoint.
- The managed-server journey and the already-running-server journey each
  processed `examples/input/magazine.png` into 44 blocks plus JSON and
  Markdown. Their JSON outputs were byte-identical with SHA-256
  `620a1684e2998d06de32f989ea2b9f27aa777b4d63f211c09595dfddddbfa634`;
  their Markdown outputs were byte-identical with SHA-256
  `f28e344246cc212f5ef7e11971927fb4b3b935eabec3c57d83fb9225f7a689c8`.
- Managed and external test servers were stopped after validation.

## Acceptance

With the explicit public-network transport waiver, all remaining G5
requirements pass. This attestation makes no claim that an empty-cache public
download completed and does not broaden the G3 or G4 evidence.
