# 0.1.0 G4 Diagnostic

Status: **BLOCKED**

Run date: 2026-07-17. These runs diagnose G4; they do not authorize a release.
All runs used the frozen 27-page OmniDocBench v1.6 sample manifest
(`ae3e29039d8e4088a7887fa08c17795a83da2ec39ac761a4643d1fbf8d2690f3`),
one warm-up page, disabled prompt caching, temperature 0, seed 1, and the
G3-accepted model and pipeline.

The GPU runs pass the numerical G4 limits (mean at most 13.00 seconds/page and
nearest-rank P95 at most 34.82 seconds/page). G4 remains blocked because the
fail-closed output-equivalence check does not pass:

- both the 8-slot and 1-slot GPU results differ from the historical G3 output
  on 8 of 27 pages;
- two identical 8-slot GPU executions differ on one page, so raw byte hashes
  are not fully repeatable under that configuration;
- reducing the server to one slot reproduces GPU run 1 on all 27 pages, but
  does not restore the eight historical hashes.

This result rules out further slot tuning as a justified fix. Passing G4 now
requires an explicit, reviewable decision about the quality-preservation
contract: either reproduce the historical G3 outputs exactly, or replace raw
byte equality with a quality-sensitive equivalence method backed by accepted
evidence. The latency thresholds must not be relaxed.
