# Security Policy

Do not open a public issue for a vulnerability or include credentials, tokens, private documents, or unredacted diagnostics in a report.

Report vulnerabilities privately through GitHub Security Advisories for `AIwork4me/PaddleOCR-VL-ROCm`. Include affected versions, impact, reproduction, and mitigation when available. Public disclosure should wait until a fix and release plan are agreed.

Downloaded resources are activated only after manifest size and SHA-256 verification. A mismatch must not be bypassed.
